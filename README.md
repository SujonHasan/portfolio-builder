# Portfolio Builder

Portfolio Builder is a Next.js portfolio SaaS for creating, customizing, and publishing personal portfolio sites from one dashboard.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Copy environment variables from `.env.example` and fill in MongoDB and JWT values.

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000).

Users can register and sign in directly, then go straight to the dashboard.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
